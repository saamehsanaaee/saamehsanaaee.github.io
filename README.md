# Saameh's GitHub Page

Hey there!

This repository contains the relatively minimal code for my GitHub page. Most of the code was copy-pasted, so feel free to do the same.

My CV is automagically compiled using the `moderncv` package with style `classic`. The compiler uses `xelatex` to build the PDF.

The static page is also built using some simple `html` and `css` with *a LOT* of copy-pasting. I stole code from people who are more experienced than I am. Feel free to do the same.
