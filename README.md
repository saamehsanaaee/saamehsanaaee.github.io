# Saameh's GitHub Page

This repository contains the code for my GitHub page, built with `html` and `css`.
Most of the code was collaged together and I don't really remember where I learned or got it from.
My apologies for the lack of credits for those parts of the code.

For the CV TeX template and inspiration, however, I can give proper credit.
My CV is inspired by [Haofeng Yuan](https://xyz-yuanhf.github.io/)'s [yuan-resume](https://github.com/Xyz-yuanhf/yuan-resume) repository.
It's built with `moderncv` package with style `classic`.
The compiler uses `xelatex` to build the PDF[^1].

[^1]: I usually work with `pdflatex` but, in the yuan-resume repository, Haofeng Yuan notes that `pdflatex` won't work with the fonts used for this CV.
So, don't forget to switch to `xelatex` if you're using the template.
